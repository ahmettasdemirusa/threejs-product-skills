🧊 Three.js Product Skills

Agent skills that teach Claude Code, Codex and other AI coding agents to build 3D product viewers, configurators, AR embeds and 360° spins, with tested templates, current three.js APIs and real performance budgets.

★ View on GitHub Install the skills
Product viewerDrag to orbit, scroll or pinch to zoom. Open the template ↗
ConfiguratorColors by material name; the state goes in the URL. Open full screen ↗
360° spinThe same mug as a 36-frame image sequence in Spin360.

All three demos show the same product. The model is assets/mug-optimized.glb (31 KB after glTF-Transform), exported from three.js by tools/export_mug.py.

The skills

SkillWhat your agent learns
threejs-product-viewerLoad a GLB, auto-frame any model, studio lighting, contact shadow, orbit limits, render on demand, cleanup and budgets
product-configuratorColors, finishes, textures, parts and KHR_materials_variants; URL state, pricing, accessible option UI
3d-asset-optimizationglTF-Transform: Meshopt vs Draco, KTX2 vs WebP, budgets, and the flags that silently break configurators
model-viewer-ar<model-viewer> embeds with AR on Android and iOS, true-scale checks, variants, custom AR button
360-product-spinWhen to use a spin, how to photograph or render the frames, and embedding with Spin360
